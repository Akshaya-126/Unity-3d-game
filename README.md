# Unity-3d-game | Leap quest

Leap Quest | 3D Adventure Platformer Game

Developed a 3D adventure platformer using Unity, featuring three progressive levels set in a desert 
environment.
Implemented collectible-based progression with coins, gems, and diamonds, obstacle 
systems including bombs, moving lava, and enemy combat, and a health, timer, score, and star
rating system.
Designed level unlocking logic, third-person camera mechanics, and intuitive 
keyboard controls to create an engaging single-player gameplay experience.
